WSL是**Windows Subsystem for Linux（Windows 的 Linux 子系统）** 的缩写，是微软为 Windows 系统开发的一项功能，核心作用是让你**不用虚拟机、不用双系统，就能在 Windows 上直接运行原生的 Linux 环境和工具**。

#### 1.安装

在 Windows PowerShell（管理员）里跑：

```plain
wsl --install
```

默认装 Ubuntu，重启后自动进入设置用户名密码。完成后可用 `wsl -l -v` 查看已安装的发行版。

#### 2.WSL 基本使用

```plain
# 查看你的 WSL 版本和发行版
wsl -l -v          # 在 Windows 终端/PowerShell 里跑

# 在 WSL 里访问 Windows 文件
cd /mnt/d/IDE/VibeCoding/Claude   # 就是你当前的工作目录

# 从 Windows 访问 WSL 文件（在 Windows 资源管理器地址栏输入）
\wsl$

# 进入WSL
wsl                # PowerShell管理员里跑

# 退出WSL
exit

# 关闭WSL
wsl --shutdown      # PowerShell管理员里跑
```

#### 3.主机代理生效

主机代理不会在WSL自动生效，需要手动配置

编辑 Windows 上的 `%USERPROFILE%\.wslconfig`（如 `C:\Users\你的用户名\.wslconfig`），写入：

```plain
[wsl2]
networkingMode=mirrored
```

然后在 PowerShell 里 `wsl --shutdown` 重启 WSL。之后 WSL 内 `127.0.0.1` 直接就是 Windows 本机。

在 Windows CMD 里跑：

```plain
netstat -ano | findstr LISTEN | findstr 127.0.0.1
```

先关掉代理软件跑一次，再打开跑一次，对比多了哪个端口，就是代理端口。（如 UniClash 常见 7890/7993/9090）

WSL内执行

```plain
echo 'export http_proxy="http://127.0.0.1:7993"' >> ~/.bashrc
echo 'export https_proxy="http://127.0.0.1:7993"' >> ~/.bashrc
source ~/.bashrc
```

端口号换成你实际查到的。取消代理就删掉这两行。
