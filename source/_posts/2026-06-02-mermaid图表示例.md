## 1. 流程图 (Flowchart)

```mermaid
graph LR
    A[开始] --> B{判断条件}
    B -->|是| C[执行 A]
    B -->|否| D[执行 B]
    C --> E[结束]
    D --> E
```

```mermaid
graph TB
    subgraph 前端
        A[用户请求] --> B[负载均衡]
    end
    subgraph 后端
        B --> C[API 网关]
        C --> D[业务服务]
        D --> E[(数据库)]
    end
    subgraph 缓存层
        C -.-> F[Redis]
    end
```

## 2. 时序图 (Sequence Diagram)

```mermaid
sequenceDiagram
    participant U as 用户
    participant B as 浏览器
    participant S as 服务器
    participant D as 数据库

    U->>B: 点击登录
    B->>S: POST /api/login
    S->>D: 查询用户
    D-->>S: 返回用户信息
    S-->>B: 返回 JWT Token
    B-->>U: 跳转到首页
```

## 10. ER 图

```mermaid
erDiagram
    AUTHOR {
        int id PK
        string name
        string email
    }
    ARTICLE {
        int id PK
        string title
        text content
        datetime created_at
        int author_id FK
    }
    TAG {
        int id PK
        string name
    }
    ARTICLE_TAG {
        int article_id FK
        int tag_id FK
    }
    AUTHOR ||--o{ ARTICLE : "撰写"
    ARTICLE ||--o{ ARTICLE_TAG : "拥有"
    TAG ||--o{ ARTICLE_TAG : "标记"
```
