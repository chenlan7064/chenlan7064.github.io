# 张量

# 张量初始化

通用可选参数:

dtype：指定数据类型，比如 torch.float32 或 torch.int64，不填就自动猜。

device：指定存在GPU还是CPU

requires_grad：设为 True 就能让张量跟踪梯度，用于模型训练，默认是 False。

# 从数据直接创建

torch.tensor(data):直接从给定数据data创建张量。

# 创建具有特定填充值的张量

torch.zeros(size)：创建一个值全为零，shape为size的张量。size可为元组或直接输入shape

  • 典型用途：初始化偏置项、创建占位符。

torch.ones(size)：创建一个值全为一的张量。 同上

  • 典型用途：初始化归一化层、创建全一掩码。

torch.full(size, fill_value)：创建指定形状、元素全部填充为给定值 fill_value 的张量。

torch.zeros_like(input)/torch.ones_like(input)/torch.full_like(input, fill_value)：创建一个shape与input张量相同，值全为0/1/fill_value的张量

# 创建随机初始化张量

torch.randn(size)：创建一个遵循标准正态分布的张量。 权重初始化的常用选择

torch.normal(mean, std, size, generator=None, out=None)：创建一个遵循标准正态分布的张量。

  • mean：指定均值
  • std：指定标准差
  • size：指定输出张量的形状
  • generator：指定随机数生成器，用于复现采样结果
  • out：指定输出张量，避免重复开辟内存

torch.rand(size)：创建一个遵循01均匀分布的张量。

torch.randint(low，high，size)：在区间 [low, high) 内生成随机整数，形成指定形状的张量。

torch.empty(size)：分配指定形状的未初始化内存。其值取决于当时内存状态，是随机的。通常不直接用于初始化参数，而是作为某些操作的中间步骤。

# 创建序列张量

torch.arange(*start=0，end，*step=1)：创建一个从 start 到 end（不包括end），步长为 step 的一维序列张量。

torch.linspace(start，end，step)：创建一个在[start，end]**(特例，一般是左闭右开)**上等距生成step个点的一维张量

# 创建特殊矩阵

torch.eye(n)：创建 n × n 的单位矩阵（主对角线为1，其余为0）。

# 从外部库（Numpy）创建张量

torch.from_numpy(ndarray)：从 NumPy 数组 ndarray 创建张量。

关键点：返回的张量与 NumPy 数组共享底层内存，修改一个会影响另一个。

# 张量属性

注：以*指代执行以下方法的张量

# 基础属性

*.shape/*.size()：张量形状

*.dtype：张量中每个元素的数据类型

*.device：张量所处计算设备（CPU/GPU某张卡）

*.nidm/*.dim()：张量的秩（shape元组的长度）

*.numel()：返回张量中所有元素的总个数，即 shape 中各维度大小的乘积

len(*)：返回张量第0维的长度

# 计算图相关属性

*.requires_grad：指示是否对该张量进行梯度跟踪，通常在创建张量时指定，默认为False

*.grad：存储张量的梯度。在调用 backward() 进行反向传播后，如果该张量的 requires_grad 为 True，且是计算图中的叶节点，其计算出的梯度将存储在此属性中。在反向传播之前为 None

*.is_leaf：指示该张量是否为计算图中的叶节点。叶节点通常指由用户直接创建（而非通过其他张量运算得到）且 requires_grad=True 的张量。叶节点的梯度在反向传播后会被保留。

# 张量操作

*.reshape(shape)：张量形状变为shape，shape的某个特征维度可为-1，pytorch框架会自动计算该维度大小。

# 采样

multinomial.Multinomial(total_count, probs=None, logits=None)：

  • total_count为整数，单次实验中总共进行的独立试验次数
  • probs为形状为[k]的张量，表示k个互斥事件各自发生的概率，要求所有元素和为1，支持未归一化的权重，会自动转换为概率
  • logits和probs二选一，是概率的对数形式，适合数值不稳定场景下使用
